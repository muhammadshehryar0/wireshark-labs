Lab 03: DNS Tracking

Objective
To analyze DNS queries and responses and understand domain name resolution.

Tool Used
- Wireshark

Steps Performed
- Captured DNS traffic
- Filtered DNS packets
- Identified Type A records
- Observed multiple IP addresses in responses

Filters Used
dns 

Observations
- DNS translates domain names into IP addresses.
- Type A records return IPv4 addresses.
- Multiple IPs are used for load balancing and CDN services.

Key Learnings
- DNS working mechanism
- Query and response structure
- Role of multiple IP addresses
