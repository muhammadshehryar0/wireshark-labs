Lab 01: Basic Packet Identification

Objective
To understand basic network traffic and identify different types of packets using Wireshark.

Tool Used
- Wireshark

Steps Performed
- Started packet capture on active network interface
- Generated traffic by browsing websites
- Stopped capture after collecting packets
- Identified different protocols

Filters Used
dns 
http
tcp


Observations
- Multiple types of packets were captured including DNS, TCP, and HTTP.
- Each protocol serves a different purpose in communication.
- TCP ensures reliable data transfer between client and server.

Key Learnings
- Understanding packet types
- Basic Wireshark interface usage
- Introduction to network traffic analysis
